### [FAQ page enhancement with auto-scroll feature @ 0:34](https://fathom.video/calls/647171669?tab=summary&timestamp=34)

### [Critical Divi 5 CSS caching bug affecting client site @ 12:04](https://fathom.video/calls/647171669?tab=summary&timestamp=724)

Kevin and Bellwether identified a severe CSS caching issue on a Divi 5 website where the front end displays incorrectly formatted content while the Edit with Divi backend shows proper formatting. The problem occurs daily or multiple times per day, requiring manual CSS cache clearing to fix. Since the client sells worship event tickets, incorrect site formatting directly impacts revenue. The team confirmed that Critical CSS is already disabled and that clearing the cache temporarily resolves the issue, but they need a permanent proactive fix rather than repeated manual interventions.

### [Submitting detailed support ticket to Divi @ 16:00](https://fathom.video/calls/647171669?tab=summary&timestamp=960)

Kevin and Bellwether navigated the Divi support portal to submit a comprehensive ticket about the CSS caching issue. They enabled remote access, copied the support token, and drafted a message emphasizing that: (1) the problem occurs during normal site visits, not editing; (2) they've already cleared the CSS cache and confirmed it works; (3) they need a proactive fix, not a reactive workaround; and (4) they requested human support rather than an AI agent. Kevin will monitor his inbox for Divi's response.

### [SiteGround caching plugin configuration troubleshooting @ 22:07](https://fathom.video/calls/647171669?tab=summary&timestamp=1327)

Bellwether identified that the SiteGround Speed Optimizer plugin's dynamic caching setting must be disabled within the plugin settings before disabling the plugin itself, as server-side caching persists even after plugin deactivation. He shared this insight from previous experience with WP Rocket where SiteGround caching continued in the background undetected. The team decided to purge the SiteGround cache, disable dynamic caching in the plugin settings, then disable the plugin entirely.

### [New Divi form builder features and roadmap @ 29:40](https://fathom.video/calls/647171669?tab=summary&timestamp=1780)

Divi released new form features including: radio buttons, checkboxes, input fields with editing options; state styling for focused, active, and checked states; and a Contact Form 7 (CF7) module allowing visual editing of CF7 forms directly in Divi. While this doesn't provide full form builder capabilities like rows, it improves CF7 form appearance. Bellwether noted this is the first round of form improvements and expressed interest in future support for Ninja Forms and Fluent Forms, which he mentioned in the comments.

### [Pricing structure optimization for AI platform @ 47:35](https://fathom.video/calls/647171669?tab=summary&timestamp=2855)

Bellwether restructured the pricing tiers to create a clearer upgrade path and better value perception:

  - **Free**: Only Perplexity (encourages upgrade)
  - **Starter**: Perplexity, Claude, ChatGPT (moved from Pro to capture ChatGPT-focused users)
  - **Professional**: Perplexity, Claude, ChatGPT, Google Gemini (removed from Agency)
  - **Agency**: Brave, Exa, Tavli, Grok, Google AI overviews, AI mode, Copilot (up to 11 platforms total)
  - Removed competitor benchmarking and share of voice analysis from free plan (shows detection but not analysis)
  - Moved Projects feature from Starter to Pro only (planning additional features)
    The changes slightly reduced margins but created more balanced tiers and stronger upgrade incentives.
